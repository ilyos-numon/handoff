# 90초 데모 영상 대본

공개 데모 `/demo` 한 페이지(팀장·퇴사자·후임 화면 나란히)에서 [시연 시나리오](demo-scenario.md) 11~18단계를 따라간다. 1~10단계(자료 불러오기·질문 만들기·사전 부검·우선 질문·세션 1회)는 데모가 미리 채워 두므로 영상은 후임의 첫 질문부터 시작한다. 장면 순서는 `scripts/record_demo_video.py` 의 녹화 순서와 같다.

"재녹화 시 바뀜" 표시가 있는 장면은 2026-10-29 화면(도움말 "?"·팀장 탭 3개·질문 대화 화면)이 들어가 현재 `docs/media/demo.mp4` 와 다르다.

## 장면

| # | 시간 | 화면 | 자막 | 설명 |
|---|------|------|------|------|
| 1 | 0:00–0:08 | `/demo` 세 화면 나란히 | 링크 하나로 세 역할 화면 | 방문자 전용 연습 공간이 생기고 퇴사자 첫 세션 답이 이미 기록돼 있다. API 키 없이 녹화된 답을 재생한다 |
| 2 | 0:08–0:20 | 후임 화면 질문하기 (단계 11) | 후임은 기록에 묻는다 | "결제 대행사 장애가 나면 무엇을 먼저 확인하나요?" → 세션 1 근거와 함께 답. 전화번호는 `[전화번호]` 로 가려진다 |
| 3 | 0:20–0:30 | 후임 화면 질문하기 (단계 12) | 기록에 없으면 지어내지 않는다 | 캐시 서버 재시작 질문은 "인수인계에 없습니다" 로 답하고, 퇴사자 질문 목록에 올려 다음 세션에서 묻는다 |
| 4 | 0:30–0:38 | 후임 화면 이건 왜 이렇게? (단계 13) | 이유가 없으면 없다고 말한다 | "금요일 배포 금지" 의 이유는 기록에 없다고 답하고, 관련 위험(작년 금요일 배포 사고)만 보여 준 뒤 퇴사자 질문 목록에 올린다 |
| 5 | 0:38–0:50 | 팀장 화면 빈 곳 보기 탭 + "?" 도움말 (단계 14~15, 재녹화 시 바뀜) | 팀장은 빈 곳만 본다 | 축별 진행 상황과 빈 구멍. "?" 를 열어 "다른 사람의 답변 내용은 보이지 않는다" 는 안내를 보여 준다 |
| 6 | 0:50–1:00 | 팀장 화면 질문 남기기·자료와 문서 탭 (단계 14·16, 재녹화 시 바뀜) | 질문을 남기고 런북을 만든다 | 다음 세션 질문 큐에 후임 질문이 대기로 보이고, 운영 런북을 만든다. 런북에도 전화번호는 가려진다 |
| 7 | 1:00–1:12 | 퇴사자 화면 세션 2 (단계 17) | 매일 15분, 퇴사자가 답한다 | 세션을 시작해 넘어온 캐시 질문에 답하고 세션을 마친다 |
| 8 | 1:12–1:22 | 후임 화면 같은 질문 다시 + 넘긴 질문 탭 (단계 18, 재녹화 시 바뀜) | 넘긴 질문에 답이 돌아온다 | 같은 문장으로 물으면 세션 2 답이 근거로 나온다. 넘긴 질문 탭에서 대화로도 본다 |
| 9 | 1:22–1:30 | 팀장 화면 전체 크기 (재녹화 시 바뀜) | 답 원문은 내가 남긴 질문만 | 역할 전환 막대로 팀장 화면을 연다. 큐에서 답변됨 상태를 확인하고, 답 원문은 본인이 남긴 우선 질문만 열린다 |

## 녹화 방법

```bash
uv sync
uv run playwright install chromium   # 처음 한 번
uv run python scripts/record_demo_video.py
```

- 스크립트가 빈 포트에 데모 서버(녹화본 재생, LLM 호출 없음)를 띄우고 `/demo` 를 위 순서대로 조작한 뒤 ffmpeg 로 `docs/media/demo.mp4` 와 하이라이트 `docs/media/demo.gif` 를 만든다. 중간 파일은 `out/video/` 에 남는다.
- ffmpeg·ffprobe 가 필요하다. 스크립트는 `/opt/homebrew/bin/ffmpeg`, `/opt/homebrew/bin/ffprobe` 경로를 쓴다.
- 현재 `docs/media/demo.mp4` 는 2026-10-23 녹화라 도움말 "?"·팀장 탭 3개·질문 대화 화면이 없다. 팀장 화면이 한 페이지 두 단이던 때의 화면이다.
- 다시 녹화하면 바뀌는 장면:
  - 5: 팀장 화면이 탭 3개(빈 곳 보기·질문 남기기·자료와 문서)로 나뉘고, 패널 제목 옆에 "?" 가 생긴다.
  - 6: 질문 큐는 질문 남기기 탭, 업무 자료·산출물은 자료와 문서 탭으로 옮겨져 탭을 눌러야 보인다.
  - 8: 후임 화면에 넘긴 질문 탭과 대화 화면이 생기고 "다시 묻기" 버튼이 없어졌다.
  - 9: 팀장 화면 전체 크기도 탭 구조로 보이고, 내가 남긴 질문 패널이 있다.
- 지금 녹화 스크립트는 탭을 누르는 동작이 없다. 팀장 패널이 선택되지 않은 탭 안에 숨겨져 있어 장면 5·6·9 에서 멈출 수 있으므로, 재녹화 전에 스크립트에 탭 선택을 더해야 한다.
