떠나는 사람이 무엇을 아는지 모르는 채 쓰이는 인수인계 문서 대신, 질문으로 지식을 꺼내 남기는 도구의 데모입니다.
팀장·퇴사자·후임 세 화면을 나란히 놓고, 방문자마다 따로 만들어지는 연습 공간에서 직접 눌러 볼 수 있습니다(24시간 뒤 자동 삭제).
로그인 쿠키 때문에 이 페이지 안이 아니라 `https://<owner>-<space>.hf.space/demo` 직접 주소로 여는 것이 좋습니다.
